KMT reduces decisions but spends more propagations. **Do not deploy it for
throughput on this evidence.** The memory improvement alone does not justify
reopening MCF, global cardinality rewriting, or another wall search. The
original paired per-call receipts are in `bench/` and `bench-1m/`; the
`replicates/` directory contains the deterministic counter checks.

## Boundaries

The large $n=30,41$ extension tests use positional witness families, not full
assignment enumeration. These are implementation and allocation receipts, not
a Lean proof of whole-parent equivalence. A SAT model must be projected back
through the allocation map and checked against stock; a proof belongs only to
the exact KMT hash. No SAT or UNSAT verdict was obtained here.

Nothing proves physical candidate criticality, a coded guard equals `Sends`, or
`ChainReady`. The interval remains $51\le R_4(3)\le62$.
