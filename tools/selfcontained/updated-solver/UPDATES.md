# Provenance inventory

The archive was copied from the original `dist/k58-solver.zip` (version
`2026-11-26-wallcc`) before adding files. No member `m*` artifact or source
was installed as a background daemon, plugin or production job.

New solver interfaces:

* `tools/` unchanged stock package plus `square_spoke/`, based on
  `research/k58-square-spoke-wall-test/` and the independently replayed parent
  reconstruction programs. The K15 theorem uses 315 variables / 1,825 clauses;
  there are 14 ordinary first-tier walls, not 13 full-root historical rows.
* `color-resolved-wallcc/`, exactly the separately validated copy candidate
  from the repository's color-pivot work. Its default `tools/drat-trim` binary
  is byte-identical to the package's root `bin/drat-trim`.
* `paired_arm/`, the finite scripts for the accepted historical hard1300
  paired/transversal/two5 work plus a fail-closed dispatcher. Local-path
  defaults were changed to point into this package, not ephemeral `.scratch/`.
  The literal bank/previous work is only a conditional tool family; no generated
  model/proof or timing is hidden as a production closure.

`modified-manifest.json` records SHA-256 for each newly supplied source/data
file. It does not claim that an optional search result is a proof. See the
original handoff documents for stock ledger/queue/storage assumptions.
